# 篮球人生 — 独立 Web 版实现计划（v3：自定义无限制提示词 + 世界书）

技术栈：Node.js + Express，前端原生 HTML/CSS/JS 单页应用，无构建步骤。LLM 走 OpenAI 兼容接口（base_url/api_key/model 存于 config.json）。

## 文件结构

```
BBL_new_GLM5.3/
├── server.js              # Express：API + LLM 代理 + 默认提示词 + 世界书接口
├── package.json           # express（端口 3000）
├── config.json            # { api_key, base_url, model }（占位）
├── prompts.json           # 用户自定义提示词覆盖（含 unrestricted_prompt 字段，默认空）
├── worldbook/             # 世界书目录（JSON，可多个）
│   ├── cba.json           # CBA 队伍与人员（上海久事大鲨鱼等，含教练/本土/外援名单）
│   └── nba.json           # NBA 队伍与人员（分赛区球队、代表球星等）
├── data/                  # save_{slot}.json 与 snapshots/
└── public/
    ├── index.html
    ├── css/style.css      # 暗色篮球主题
    └── js/
        ├── app.js         # 主控制器
        ├── state.js       # ##STATE## 协议（移植自 BBL_new）
        ├── game.js        # 试玩模式预设剧情
        ├── llm.js         # _ll / _ls 客户端
        ├── memory.js      # narrativeHistory / memoryLog 管理
        ├── worldbook.js   # 前端世界书加载与按阶段/球队选择性注入
        └── ui.js          # 叙事打字机、选项、侧栏属性面板、设置页
```

## 无限制提示词（用户自选）

- `prompts.json` 含 `unrestricted_prompt` 字段，**默认为空字符串**——不预置任何越狱内容，仅提供一个用户可自行填写/留空的文本框（设置页内，注明"由用户自行决定填写内容并承担相应责任"）
- 组装 system prompt 的顺序：基础游戏引擎提示词 + 世界书条目 + （若用户填写了）其自定义 unrestricted_prompt 追加在末尾
- `/api/prompts/default` 返回默认三项模板；`GET/POST /api/prompts/custom` 读写 prompts.json（前端设置页提供编辑框，含基础 system_prompt 与 unrestricted_prompt 两栏）

## 世界书（worldbook/）

- **cba.json**：联赛概况 + 各队名单（重点：上海久事大鲨鱼完整 roster——教练卢伟，王哲林/刘铮/李添荣/张镇麟/李弘权/袁堂文等，外援洛夫顿/古德温/弗格/怀特塞德，参考 BBL_new 已验证数据），每名球员含 position/height/age/desc
- **nba.json**：30 队按东西部分区，每队列代表球员与风格描述（数据为通用常识性配置，用户可自行编辑 JSON 扩充）
- 每个条目带 `keywords` / `stage` 触发条件：state.story_stage 或当前叙事提及的队伍名命中时才注入 prompt（控制 token），开局/换队时注入所属球队完整名单
- API：`GET /api/worldbook`（列表+内容）、`POST /api/worldbook`（保存编辑）；设置页提供世界书查看/编辑界面
- 提示词中要求 LLM 使用名单中的真实名字，禁止编造不存在的球员

## 状态协议（state.js，移植自 BBL_new）

- `extractState`（容错 + 剥离 ```json 围栏）、`extractChoices`（---CHOICES--- 及多分隔符兼容 + 数字行回退）、`cleanNarrative`
- `normalizeRelationships`（type/level/notes → name/relationship/status/trust）
- `mergeState`（浅合并 + stats 深合并 + attributes 钳 0-99 + energy 钳 0-100）
- 字段集：player（name/age/position/height/weight/charm）、attributes 7 项、season（team/league/stats/nextGame）、relationships、reputation、story_stage、money、energy、narrativeHistory、memoryLog
- localStorage `bbl_save_{slot}` + 服务端双写存档、ts/rs 快照封装

## 提示词模板（结构参考 BBL_new）

- **system_prompt**（基础，默认启用）：沉浸式篮球人生游戏引擎；中文、单场景≤2000字、禁 ##小标题、结尾必带 ##STATE## + ---CHOICES--- 3-4 个上下文相关选项、属性随选择增减
- **game_intro**：{name}/{position}/{height}/{weight}/{background} + 初始 STATE 示例
- **game_action**：注入 {state}、{action}、世界书命中条目、narrativeHistory 摘要

## 后端 API
`GET/POST /api/config`（key 脱敏）、`POST /api/llm/non-stream`（_ll）、`POST /api/llm/stream`（_ls，SSE `data: {json}\n\n`）、`/api/save` + `/api/load/:slot` + `/api/saves`、`/api/snapshot`(ts) + `/api/snapshot/restore`(rs)、`GET /api/prompts/default`、`GET/POST /api/prompts/custom`、`GET/POST /api/worldbook`

## 游戏流程
标题屏 → 新游戏（选起始舞台：高中/CBA/NBA，姓名/位置/身体条件/背景）或读档 → 开局 `_ll`（未配 key 走试玩剧情）→ 流式叙事打字机 → 选项/自由输入 → `_ls` → 合并状态刷新侧栏 → 自动存 auto → 每回合 ts 快照，UI 可 rs 回退重生成。设置页：LLM 配置、提示词编辑（含 unrestricted_prompt 自填栏）、世界书编辑、存档管理。
